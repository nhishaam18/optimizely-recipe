# Phase reference

For this recipe use the authoritative [five-phase flow](desktop-demo-flow.md) and [operation contract](operation-contract.md). Intake and setup precede source annotation; documentation and Specialist review precede user approval; Phase 3 tasks are generated from that approval; tenant configuration/composition and release require scoped user-approved batches. No additional legacy migration phases are implied.

Explicit implementation-only requests use [implementation entry](implementation-entry.md) with approved artifacts and actual authorization; they do not require restarting discovery. Documentation requests never enter that path.
